# Inspektorat Jenderal Kementerian Perdagangan RI - CJM & Audit 5C

Instrumen Evaluasi Pelayanan Publik Berbasis Citizen-Centric (Citizen Journey Mapping) terintegrasi dengan Kertas Kerja Pengawasan Internal 5C (Condition, Criteria, Cause, Consequence, Recommendation).

## Fitur Interaktif Baru
- **ContextMeter**: Visualisasi beban administratif (Beban Pembelajaran, Beban Kepatuhan, Beban Psikologis) dengan matrix indikator dan filter otomatis.
- **UploadDropzone**: Unggah berkas bukti lapangan dengan animasi seret/lepas, validasi ukuran berkas, indikator progres, dan badge format.
- **ActionNodeCard**: Kartu tahapan layanan interaktif dengan indikator denyut status, konektor socket alur, kontrol lipatan sudut, dan pintasan cepat kertas kerja 5C.
- **PerspectiveAssetSwap**: Penukar perspektif instan (Lensa Pengalaman Warga ⇄ Lensa Pengawasan Auditor Itjen).
- **PullToRefreshSync**: Penarik taktil sinkronisasi status kanvas dengan umpan balik visual dan status simpan otomatis.
- **GenerativeInsightCard**: Asisten sintesis AI Generatif Co-Design untuk mengekstraksi akar masalah layanan dan merumuskan rekomendasi perbaikan standar SLA.
